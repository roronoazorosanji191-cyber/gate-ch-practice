# GATE CH Practice — Frontend V1

A mobile-first React/Vite demo based on the supplied product specification.

## Run
1. Install Node.js 18+.
2. In this folder run `npm install`.
3. Run `npm run dev`.
4. Open the local Vite URL.

## Included
- Responsive mobile/tablet/desktop layout
- Home dashboard
- Practice, PYQ filters and search
- 15 sample/demo questions with MCQ/MSQ/NAT formats
- Question-solving flow with explanations
- Question palette
- Mock-test intro, test and result screens
- Predicted-question practice
- Progress analytics
- Bookmarks and wrong-question review
- Profile/settings
- Persistent dark mode and bookmark/wrong state via localStorage
- Reusable UI/data architecture
- No backend, auth, payments, ads, or database

All question content is explicitly demo/sample content, not claimed as official GATE PYQs.
